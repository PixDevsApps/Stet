# Assets and provenance

Project: Stet, a fast, keyboard-first text and code editor for Omarchy

Synced: 2026-10-02

The repository docs are the canonical project memory ([ADR-012](DECISIONS.md)). Dated entries describe the state at that date; newer entries take precedence.

---

Every image, icon and fixture in the repository is listed here with its origin. Nothing comes from an image-generation service, and nothing third-party is bundled.

## Test fixtures — 2026-10-01

| File | What | Origin | Ships |
| --- | --- | --- | --- |
| `tests/selftest/themes/stet-dark/colors.toml`, `tests/selftest/themes/stet-light/colors.toml` | Synthetic Omarchy themes for the theme self-test | Original colour values in Omarchy's `colors.toml` format; not copies of Omarchy themes. MIT. | No |

The preview script (`tests/selftest/preview.stet-test`) reads Omarchy's installed themes from `/usr/share/omarchy/themes/` at run time and copies nothing into the repository.

The M3 self-tests (2026-10-01) add no fixture files. They write their files at run time into a temporary directory: `encodings.stet-test` from hex in the script, mirroring the infrastructure tests' corpus in `infrastructure/src/encoding/fixtures.rs`; `convert.stet-test` and `disk.stet-test` small files of their own; `large.stet-test` logs, Rust, JSON and XML generated by `app/src/selftest/generate.rs`. The sample sentences are original.

## Screenshots

`docs/images/stet-tokyo-night.png`, the README's screenshot (2026-10-01, 1.3), was rendered headless under GTK Broadway by `stet --self-test tests/selftest/preview-readme.stet-test` in Omarchy's installed tokyo-night theme; its text is written by the script. MIT, like the rest of the repository.

`tools/progress/public/` holds preview-gate screenshots of Stet itself. The M1 ones (`m1-*-2026-10-01.png`) were rendered headless under GTK Broadway by `stet --self-test tests/selftest/preview.stet-test` with the Cairo renderer, in Omarchy's tokyo-night, catppuccin-latte and gruvbox themes. They show only Stet's own UI and sample text written by the script. The M3 ones (`m3-*-2026-10-01.png`) come from `tests/selftest/preview-m3.stet-test` the same way, in the same three themes.
